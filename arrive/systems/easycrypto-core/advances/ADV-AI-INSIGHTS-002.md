## Objective

**Part 2 of 4** of the on-device AI insights feature. Introduce the Apple
**Foundation Models** dependency and the `FoundationModelInsightEngine` that turns
the bounded `TradeSummary` from ADV-AI-INSIGHTS-001 into typed `TradingInsight`
suggestions — running **entirely on device** (iOS 26+), with no network and no
remote/cloud fallback. Depends on ADV-AI-INSIGHTS-001 (`TradeSummary`,
`TradingInsight`).

## Behavioral Change

After this advance:
- Calling the engine with a `TradeSummary` produces typed `TradingInsight`s
  generated by an **on-device** `LanguageModelSession` (`SystemLanguageModel.default`).
- Output uses **guided generation**: a `@Generable` `TradingInsightDraft`
  (constrained fields + `@Guide` descriptions) is requested via
  `session.respond(generating:)`, then mapped to `TradingInsight` — no free-text
  parsing.
- The engine first checks `SystemLanguageModel.default.availability` and returns a
  typed `InsightAvailability` (`available` / `unavailable(reason)`) instead of
  crashing on unsupported devices.
- The engine is reachable only through a protocol seam so its mapping/availability
  logic is unit-tested with a fake session — no real LLM call in tests.
- No UI and no background scheduling yet (Parts 3 and 4).

## On-Device-Only Constraint (non-negotiable)

- Uses **only** `import FoundationModels` / `SystemLanguageModel.default`.
- The engine performs **no** `URLSession`/network I/O and consumes only the
  in-memory `TradeSummary` (never raw trades).
- No prompt or summary is logged off-device or sent to analytics.

## Design Notes

- **ai-insights** (`EasyCrypto/Core/AI/**`):
  - Add `@Generable` `TradingInsightDraft` (constrained `category`/`severity`,
    `@Guide`-described `title`/`body`/optional `symbol`).
  - Define an `InsightSession` protocol seam (`respond(generating:)`) with a thin
    production adapter over `LanguageModelSession`; tests inject a fake.
  - Add `FoundationModelInsightEngine`: checks availability, builds a compact
    instruction + prompt from `TradeSummary`, requests `[TradingInsightDraft]` via
    guided generation, maps drafts → `TradingInsight`, and surfaces
    `InsightAvailability`. `@available(iOS 26, *)`; off-main-actor friendly.

## Risk + Rollback

- Risk: new_dependency — adopts the `FoundationModels` framework; guard all use
  behind `SystemLanguageModel.default.availability` and `@available(iOS 26, *)` so
  unsupported devices degrade gracefully instead of crashing.
- Risk: privacy — keep the engine path free of any network I/O and ensure only the
  bounded `TradeSummary` (never raw trades) is passed to the model; never log
  prompts/summaries off device.
- Risk: nondeterminism — use guided generation (`@Generable`) for typed output and
  isolate the model behind the `InsightSession` seam so engine logic is testable
  without invoking the LLM.
- Risk: concurrency — engine runs off the main actor; keep inputs/outputs `Sendable`.
- Rollback: engine is unused by any surface until Part 3/4; revert the advance's
  commits.
